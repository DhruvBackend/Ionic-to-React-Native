## Quirks


1. **Entry.** Pushed by Home: scan() with `manual_permission == 1` pushes with no params, the 'code' choice of the radio alert (goToQrCode) pushes `{mode:'home'}`. The page never reads `navParams`. Roles: Plumber only (Home guards on status 'Verified'). No feature flag.
2. **Template.** Header `main-header remove` (back button visible, title "Enter Coupon Code"). Grey paragraph "Please enter coupon code here, to get your points", a bare `<input type="text" placeholder="Coupon Code">` (NOT ion-input: no maxlength, no validation, default keyboard, Chrome default border), "Required" under it when `!data.code && flag==1`, full-width Submit button (`cs-btn`, always enabled: there is no disabled logic), and the `qr_code_2` Material icon with "Tap on scan icon to scan your coupon". Only the icon (not the text) triggers scan().
3. **submit(data.code).** `flag = 1`, then POST `app_karigar/karigarCoupon {karigar_id, qr_code}`. `qr_code` is undefined (key dropped from the JSON) when nothing was ever typed, '' when emptied: the request is sent either way (the "Required" text does not block). Alerts (title `Alert!`, cssClass `action-close`, button OK): BLANK "This Coupon Code doesn't contain any Value", INVALID "Invalid Coupon Code", REQUIRED "Please Enter Coupon Code", POINTS NOT EXIST "No Points Exit This Product" (typo kept), USED "Coupon Already Used" (no user/date, unlike Home), UNASSIGNED OFFER "This Coupon Code is not applicable in your Area". Any other status or body (also `{}` / SUCCESS without coupon_value) is a success: `Success!` alert "<coupon_value> points has been added into your wallet" ("undefined points ..." when missing) and `setRoot(Tabs, {index:'0'})` (RN: `reset` to Tabs; the alert stays open over Tabs).
4. **scan().** `barcodeScanner.scan()` with no options; cancel gives text '' -> logs "not scanned anything"; denied / plugin error: no catch, nothing happens. Non-empty text -> the same POST with the scanned text (the typed code is ignored). Shorter branch list than submit(): INVALID "Invalid Coupon Code", USED "Coupon Already Used", UNASSIGNED OFFER "Invalid Coupon Code" (different text from submit), REQUIRED "Please Enter the coupon code " (trailing space). BLANK and POINTS NOT EXIST are NOT handled here: they fall through to the success alert with "undefined points" and setRoot(Tabs).
5. **No loader, no error callback.** A failed request, or a null body (TypeError inside the subscribe callback), does nothing visible. Double taps send the request twice.
6. **i18n.** coupan-code.module.ts imports only IonicPageModule (no TranslateModule), the page injects no TranslateService and every text is a literal: nothing is translated, whatever language is selected (no `hin` state).
7. **Storage keys.** None. Reads `dbService.userStorageData.id` only.
8. **Dead/odd.** `ionViewDidLoad` only logs; `mode` param unused; the `flag` stays 1 after the first Submit.
9. **After a successful redeem** Ionic leaves the app on Tabs tab 0 (Home), which re-reads karigarHome on entry (new balance); the success alert is on top. PointList shows the new balance when opened.
