## Quirks

Filled from `src/pages/tabs/tabs.html` / `tabs.ts` (no tabs.scss, no tab-specific rules for the `.tabs` wrapper in variables.scss). **File layout:** Tabs is not a normal screen. It is registered directly in `RootNavigator` (`Root.Screen name="Tabs" component={RoleTabs}`), so this folder has only `card.md` and `Tabs.test.tsx` and no `index.tsx`/`route.ts` (a second 'Tabs' route would clash; `gen-routes` skips folders without them). The container code stays in `src/navigation/{RoleTabs.tsx,tabs.ts}` and `src/components/ionic/IonTabs.tsx`.

1. **Params.** `index` (always a string where passed: '0' tabs.ts callers edit-profile/enquiry/feedback/coupan-code/task-close/..., '3' cancelpolicy-modal, shipping-detail, '4' edit-profile:195) and `lang` (only logged; `use()` is NOT called here, Otp already did). Otp pushes `{lang}` (no index), Registration and PointList push with no params; `selectedIndex="{{index}}"` then interpolates '' (undefined renders as empty).
2. **selectedIndex.** Ionic `Tabs.initTabs`: `isBlank ? 0 : parseInt(selectedIndex, 10)`; a missing, NaN, hidden or out-of-range index selects the first tab. Index counts POSITIONS in the role's set: '4' is Profile for Customer/Retailer but Menu for the loyalty roles; '3' is About Us vs Profile. RN: `parseInt` + range check (RoleTabs).
3. **Four *ngIf blocks by `userStorageData.type`** (read live from `dbService`): Customer and Retailer (identical, Home, New Arrivals, Contact Us, About Us, Profile); Plumber/Sales_Boy/Dealer (Home, Offers, My Wallet, Profile, Menu); Sales_Executive (same, Home root is SalesExecHome). Any other type (SFA, Employee, '1', none): no block matches, the page is empty with no tab bar. A missing `userStorageData` throws in the constructor (`.type` of undefined), also a blank page. RN renders an empty view for both.
4. **Titles** `{{ 'Home' | translate }}` etc.: re-evaluated on language change (RN `t(tab.title)`); keys Home, New Arrivals, Contact Us, About Us, Profile, Offers, My Wallet, Menu all exist in hin. No badges, no tab-change handlers, no events subscribed in TabsPage (app.component's events are only side-menu opens), no `tabsHideOnSubPages` (IonicModule.forRoot(MyApp), default false: each tab keeps its own stack with the bar visible, RoleTabs).
5. **Constructor, token empty/null.** `rootPage = SelectRegistrationTypePageModule` (a module, not a page) is assigned but TabsPage's template never uses `rootPage`: no effect. Not ported.
6. **Constructor, `index == '5'` with a token:** `navCtrl.setRoot(ProfilePage)` replaces the whole root with Profile (no tab bar). Every caller passing 5 is commented out, so it is unreachable in production. Ported anyway in RoleTabs (`resetTo('Profile')`, NOTE parity), unit-tested; no parity state. Without a token, index 5 is out of range, so the first tab shows.
7. **Other constructor code** (storage.get('userStorageData') then console.log, `if type == 'Plumber' {}`, console.logs, unused `@ViewChild(Nav)`, `push`, `translate`, `lang` fields) is dead. Not ported.
8. **Tab roots:** tab1 Home, tab2 Newarrivals, tab3 Contact, tab4 About, tab5 OfferList, tab6 MainHome, tab7 PointList, tab8 Profile, SalesExecHome (string name). All verified equal to `tabs.ts` here. Ionic builds a tab's root lazily when first selected.
9. **Parity scope.** The tab ROOT pages are other screens, not ported yet: the Ionic reference shows the real Home/Profile page (with no fixtures for its APIs) where RN shows a placeholder. Compare only the tab bar (icons, labels, selected underline, shadow) and the frame.
