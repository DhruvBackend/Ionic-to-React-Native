## Quirks

1. **Entry.** Transaction pushes `{id}` from every row and from the Receive button (transaction.ts:44); `offer_gift_id` is never passed, so `giftDetail` is asked with `gift_id` undefined (JSON drops the key) and only `karigar_id`. Transaction is PUSH-ONLY (the `redeem` push handlers), so this page never opens in the shipped Topbath APK; live for push-enabled clients. Every role.
2. **Loads once.** ionViewDidLoad only (no refetch): shippedDetail `{karigar_gift_id: id}`, giftDetail, then the loader `Please wait...` (dismissOnPageChange). The giftDetail response closes it (before anything is read). No error callbacks: an HTTP error leaves the loader up over the empty template.
3. **Texts.** Header `Redeem  Detail` (two spaces collapse). Title, gift title, points (parseInt: an empty gift gives NaN), Gift Status, Specification (= gift_title again), Bank Detail (4 rows). No translate, no pipes, no date pipe (estimated_date as sent). The module has no TranslateModule at all.
4. **Image.** `[src]="gift_detail.image"` as sent (no upload url in front); a bare file name is a broken image in Ionic. The first template run has src "undefined".
5. **Branches.** Shipping Detail card: `*ngIf shipped_detail.shipped_type` (`shipped` is only copied when truthy). Receive button: `*ngIf karigar_gift.receive_status != 'Received'` (also true for the initial `{}` and for an empty status).
6. **Throwing template.** karigar_gift null/missing throws at the button *ngIf (after the Shipping card's): no text is updated, the button keeps its state, and a click throws (nothing happens). gift null throws in the callback (after the loader is closed) and at `gift_detail.title`: texts stay empty.
7. **Receive.** Alert `Confirmation!` / `Did you receive this gift?` (No / Yes), POST redeemReceiveStatus `{id: karigar_gift.id, karigar_id}`; any response: `Success!` / `You have receive gift successfully`, then setRoot(TabsPage, {index:'3'}) (RN: resetTo('Tabs', {index:'3'}), a root reset). Texts identical to Transaction's, but Transaction reloads its list instead of setRoot. No error callback.
8. **ionViewDidLeave.** popToRoot when the active page is Home/GiftList/Transaction/Profile and the previous one is none of them (no MainHome).
9. **Dead/odd.** The `receive_status` field is never shown; button text typo `Recieve`; storage keys: none.
