INVALID 'Invalid Coupon Code', USED 'Coupon Already Used By <first_name> ( <mobile_no> ) on <D-M-Y>', POINTS NOT EXIST 'No Points Exit This Product' (typo), UNASSIGNED OFFER 'This Coupon Code is not applicable in your Area': alert 'Alert!' with 'Scan again' (scans again) + 'Okay'.
