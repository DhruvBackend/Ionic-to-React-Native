4. **Load.** ionViewDidLoad -> `plumber_limit` `{}` (post_rqst) sets `limit = r.limit`. No loader, no error callback; `limit` starts at 0, so while the request is pending or failed every amount is refused with "You Can  Transfer Only 0 Point ". A null body throws in the callback (only logged).
5. **submit() checks, in order, each an `Alert!` alert (title `translate('Alert') + '!'`, subTitle literal, button `ok`):** no mobile -> "Please Enter a Mobile Number"; no points -> "Please  Enter Transfer Amount" (double space, collapsed when rendered); `limit < points` -> "You Can  Transfer Only <limit> Point " (trailing space); `total_point < points` -> "You Have Insufficient Balence" (sic). The comparisons are loose JS: a numeric limit/balance is coerced against the typed string, a string limit (or balance) compares as strings ("500" < "60" is true); undefined limit/balance never blocks.
