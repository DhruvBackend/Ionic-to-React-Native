3. **Lifecycle = ionViewDidEnter.** The fetch + loader run on EVERY entry (first entry and every return from GiftDetail/Terms), not once. RN: mount effect + 'focus' after a 'blur'.

No error callback: an HTTP error leaves the loader up. Refresh (pull) shows no loader and calls `refresher.complete()` at once. Each entry creates a new loader and forgets the old one (Ionic orphans a stuck loader; RN's useLoader closes it first: not reproducible).
5. **Unguarded callback (throw points, in order).** `r.offer.length` (offer null/missing, e.g. status NOT FOUND: nothing changes, loader stays); assign offer_detail; `r.gift[0].offer_balance` (gift empty/null: header title + banner show, no list, loader stays); `r.karigar.total_balance` (karigar null: offer shows, no list, loader stays); gift_list = gift; `balance_point` (never shown); loader dismissed; coupon_points parsed with parseInt (mutates the response items). What was assigned before a throw stays shown.
